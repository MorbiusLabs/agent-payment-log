Spending rules and a tamper-evident log for AI agents that pay.

        Check a log file

        Any .jsonl log written by agent-payment-log. It is checked right here in your browser and never uploaded anywhere.

        Rules before money moves

        A cap per payment, a daily cap per agent, a list of allowed recipients, and a human sign-off for large or irreversible payments.

        Every decision is logged

        Allowed, held, denied, approved, rejected. Each entry names the rule that decided and the person who signed off.

        Anyone can check it

        Entries are hash-chained, so editing, deleting or reordering a past entry is detected. Checking needs only the file, no keys.

        Why an edit cannot hide

        Each entry stores the SHA-256 hash of the entry before it, and its own hash covers everything in it. Change one amount and that entry's hash no longer matches, and every link after it breaks.

        #0allow 12.40 USDCprev 0000…hash b14d…
        #1hold 75 USDCprev b14d…hash 7419…
        #2allow 3 USDCprev 7419…hash 5138…

        Someone who controls the whole file could recompute every hash. That is why you share the latest hash, the head, with the other side. A rewritten history no longer ends at the head they saved.

        Try it in the playground, step 5

        Use it in your agent

        Python 3.9 or newer, no dependencies.

        pip install git+https://github.com/MorbiusLabs/agent-payment-log
        from agent_payment_log import PaymentLedger, PaymentRequest, Policy, Rule

policy = Policy([
    Rule(id="data-vendors", asset="USDC", max_amount="200", daily_limit="300",
         approval_above="50", recipients=["api.marketdata.example"]),
    Rule(id="small-anything", asset="USDC", max_amount="5", daily_limit="20"),
])
ledger = PaymentLedger("payments.jsonl", policy)

entry = ledger.request(PaymentRequest(
    agent="research-agent", recipient="api.marketdata.example",
    amount="75", asset="USDC", reversible=True, memo="news archive",
))

if entry["outcome"] == "allow":
    ...  # pay now
elif entry["outcome"] == "hold":
    ledger.approve(entry["seq"], approver="ops-lead", note="known vendor")
    ...  # pay after approval

        Check a log from the command line. Exit code 0 means it checks out, 1 means it does not.

        agent-payment-log verify payments.jsonl --head HASH

        What it checks

        • The file is UTF-8, every line is canonical JSON, the last line is complete.
        • Every hash matches its entry and links to the one before it.
        • With a head hash, the log ends exactly there.
        • Only held payments get approved or rejected, each at most once, never by the paying agent, and time never runs backwards.

        What it does not do

        • It does not move money. Your agent asks first and pays only on allow or after a human approves.
        • It does not prove who wrote the log. Share the head hash for that.
        • It cannot force an agent to ask before paying.
        • One writer per log file. There is no locking between processes.

        Runs entirely in your browser. No server, no tracking, nothing is uploaded.
